# 史鉴 · 团队网站

当前线上版本：[打开网站](https://shijian-team-site-public.pages.dev/)

成员从首页「成员登录」进入后台；三个账号相互独立，共享云端资料与建议。首次登录需修改临时密码。

**当前部署源码在 [`cloudflare-site/`](cloudflare-site/README.md)。** 它包含账号认证、游客模式、文档导入、Cloudflare Pages 入口、Worker 服务与 D1 数据库。开发、部署与验证说明见该目录 README。

仓库根目录其他 HTML、Python 启动器和旧交付文档保留为早期本地原型，不是当前线上版本。请以当前线上网站和 cloudflare-site 使用说明为准。

模型服务尚未配置，当前学习空间清楚标识规则演示。独立账号密码与数据库备份不在此仓库。
