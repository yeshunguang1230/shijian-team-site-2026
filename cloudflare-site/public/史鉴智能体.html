这个项目为什么是智能体

它不是在聊天框里堆一个模型，而是把任务拆成可检查的步骤。

1. 规划

判断是事件问答、材料分析还是答题批改，决定下一步工具。

2. 检索

只从已登记的史料中找证据，并保留来源 ID 和片段。

3. 生成

将证据整理成时间线、人物关系、因果结构和学习任务。

4. 核验

检查引用是否存在，区分史实、模型推断与争议观点。

5. 反馈

按观点、证据、解释和史实准确性逐项批改。

6. 记忆

记录薄弱点，下一次练习针对薄弱点出题。

当前文件支持离线演示；配置 OpenAI 兼容接口后，回答、出题和批改会调用真实 AI。不要把 API 密钥写入代码或提交到课程材料。

AI 接口设置

支持 OpenAI 兼容的 /v1/chat/completions 接口。密钥只保存在当前浏览器本地。

公网部署由 Worker 负责代理 AI，不要在这里填写服务器密钥；只有自行连接外部接口时才在当前浏览器保存密钥。
